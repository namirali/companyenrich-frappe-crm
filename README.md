# CompanyEnrich for Frappe CRM

An independent, installable Frappe app connecting [CompanyEnrich](https://companyenrich.com/) to Frappe CRM. CompanyEnrich provides B2B company and professional-profile data through APIs for enrichment, search, lookalikes, person lookup and workforce research.

This repository is the external app's development home. It is not an upstream Frappe CRM contribution or an approved Frappe Marketplace listing.

Implementation and installation instructions are being prepared in the integration pull request. [CompanyEnrich API documentation](https://docs.companyenrich.com/reference).
